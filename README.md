# Alfredo Cisneros Romero - Website

A website to showcase professional and academic experience through GitHub Pages

## About

Providing ethical IT solutions to empower communities in Colorado. I approach IT through a public service lens in order to promote equitable and transparent technology usage.

This website serves as a professional and academic portfolio of my projects and experience within both professional and academic contexts, in order to bolster my career.

The current iteration of this website is made using StartBootstrap's "Resume" template. This will only be used for the short-term, and a more comprehensive website will be built beginning in January 2027.

## Technology

Built using HTML, CSS, [Bootstrap](https://getbootstrap.com/), and JavaScript. Credit provided to StartBootstrap for the [Resume website template](https://github.com/startbootstrap/startbootstrap-resume), freely licensed under the MIT License.
